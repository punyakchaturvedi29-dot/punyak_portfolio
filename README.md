# Punyak Chaturvedi — Portfolio

A responsive React + Vite portfolio with editorial typography, custom CSS data visualisations, interactive project filters, expandable project breakdowns, experience timeline, certification overviews, and contact actions.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. For a production build, run `npm run build`; preview it with `npm run preview`.

## Project structure

- `src/main.jsx` — React app and portfolio content.
- `src/styles.css` — responsive visual design and custom project visuals.
- `index.html` — entry HTML and page metadata.
